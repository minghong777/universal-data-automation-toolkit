# Screenshots for GitHub and Upwork

This folder contains six captures from the working application using fictional sample inputs. Captures should match the current sample-only demo; use `--uploads` only when intentionally demonstrating the trusted local workflow.

| Filename | What to show | Why it matters |
|---|---|---|
| `01-overview.png` | Application title, four workspaces and clear description | Shows a coherent, usable tool |
| `02-clean-merge.png` | Six rows → four, before/after tables and duplicate count | Demonstrates a concrete, verifiable result |
| `03-convert.png` | Flat JSON preview and CSV/Excel download buttons | Shows validated format conversion |
| `04-pdf.png` | Fictional invoice text, detected table and downloads | Demonstrates extraction without fabricated fields |
| `05-organizer.png` | Original and destination filenames, folder rules and confirmation | Shows preview-first, nondestructive file handling |
| `06-ocr-warning.png` | Warning after loading the raster-only fictional PDF | Makes limitations visible rather than hiding them |

## Capture checklist

1. Start the sample-only app for overview and common feature screenshots. Select the scanned PDF in the sample dropdown for the OCR warning. For actual uploads, explicitly enable trusted local uploads as described in the README.
2. Use only files under `samples/input/`. Never use real customer records, emails, invoices or credentials.
3. Capture around 1440 px wide, with readable text and visible results. Crop excess empty space; preserve important warnings and labels.
4. Keep desktop notifications, account menus, bookmarks, browser autofill and private paths out of the image. Screenshots generated by Playwright exclude browser chrome.
5. Choose 3–5 images for Upwork: overview, cleaning result, PDF, organizer, and optionally the OCR warning. Do not fabricate screenshots or imply a real client engagement.
6. After a UI change, regenerate the captures. Existing images are examples, not a substitute for reviewing the final published UI.

## Optional automated captures

Run the app in sample-only mode, then `python scripts/browser_smoke.py` with Playwright installed. Use `--uploads` only with a trusted local upload-enabled server. The script overwrites these six screenshots using fictional fixtures; transient downloads/reports go to ignored `artifacts/`.
